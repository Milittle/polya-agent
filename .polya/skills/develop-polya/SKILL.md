name: develop-polya
description: 在 polya-agent 仓库实现任务票或修复代码问题，完成相关验证并记录交付结果。修改引擎、工具或终端交互时使用。
---

读取项目 AGENTS.md 及与本任务相关的引用规范。任务票在 `.scratch/<feature>/issues/`；
有指定票时读取其验收条件和 Comments。修改引擎或驱动前读取 `docs/adr/0002-agent-as-generator.md`。

先用 `git status --short` 识别已有修改，再读取目标代码和测试。让修改保持在任务范围内，
保留用户已有工作。工具执行和审批由驱动负责，上下文管理由 agent 负责。

对多步任务用 todo_write 记录验收项。先跑与改动相关的测试，失败时读取具体错误、修复，
再跑受影响检查。最终按 pyproject.toml 与 README 的开发约定执行必要检查。
耗时命令返回「仍在运行」时，用 bash_output 等待真实退出码；输出省略时按行回查完整记录。

压缩后先核对摘要中的目标、用户修正、已完成检查与下一步。技能正文不在上下文时
用 skill_read 重读；不把摘要中的「预期通过」当成已执行的验证结果。

交付前检查 diff，并在任务票 Comments 追加实际修改、检查结果与剩余阻塞。
汇报已实现内容、实际运行的检查和未验证部分。遇到权限或外部服务阻塞时记录原因，
不声称验收通过。提交、推送和发布按用户本次授权执行。
